## Where to ask

- **A documentation question, a gap, or an error:** open an issue on
  [this repository](https://github.com/bitcoinuniverseio/mezcal/issues). Say which
  page and which rule.
- **A question about the Mezcal protocol itself, or its reference
  implementation:** the upstream project is
  [bitapeslabs/mezcal](https://github.com/bitapeslabs/mezcal), and the project's
  own site is [mezcal.sh](https://mezcal.sh). This repository does not speak for
  them.
- **A question about a Bitcoin Universe product:** the central documentation
  portal is <https://docs.bitcoinuniverse.io>. Product issues belong to the
  repository that owns the product.
- **A security issue:** follow [SECURITY.md](SECURITY.md). Never open a public
  issue for one.

## What this repository cannot help with

- Recovering funds. A confirmed Bitcoin transaction cannot be reversed, and a
  cenotaph burn is permanent.
- Balances, transaction status, or asset data. This repository holds no chain
  state and runs no service.
- Trading, listing, or price questions.

Nobody here will ever ask for your seed phrase, private keys, or wallet file. No
part of this documentation needs them. Treat any such request as fraud.
